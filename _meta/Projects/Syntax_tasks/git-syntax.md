Commits should be as follows:
1. A word to describe what has been done, in past tense (Updated, Added, Deleted)
2. The name of the file that has been changed
3. The group or folder of the file.

An example is if the Intimidating note under the Characteristics folder would be updated, the Git Commit would be "Updated Intimidating Characteristic". While if ideas are added to the Talents Project it would be "Added Ideas to Talent Project"
