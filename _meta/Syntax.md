# Syntax

## Emulate Syntax

### Decimals
Decimals should use the `.` symbol, while thousand separators should use `,`.

### Bonus and Penalties Linking
When linking to a specific type of bonus or penalty only the name should be linked such as a +1 [[Rules/Bonuses and Penalties/Morale|Morale]] Bonus.

### Requirements
Requirements should be shown in order of `Talents; Traits; Stats; Unique` with `;` between each requirements. The Unique Requirement is a catch all.

### Capital
The following things should always start with Capital:
- **Ability Score:** Charisma, Strength
- **Character Creation Options:** [[Commoner]], [[Regular]]

### Listing options and triggers
When listing options and triggers `;` should be used to clearly differentiate options and triggers as shown in [[Take Cover]].
