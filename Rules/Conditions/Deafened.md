# Deafened
A Deafened Creature takes a [[Circumstance]] Penalty to all [[Perception | Perception (Hearing)]] Skill Checks. The Penalty is equal to twice the Deafened value.

<br>

If the Deafened Value reaches 5, The Deafened Creature automatically fails all [[Perception | Perception (Hearing)]] Skill Checks and can not be affected by sources with the [[Language]] Trait.
