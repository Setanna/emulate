#  Gaining Actions
When you gain an Action, you gain the ability to use it. If the Action is granted only under certain conditions, you retain any benefits or penalties from using that Action even after the condition is no longer met. You simply lose access to using the Action again until the condition is met once more.

#### Gaining Multiple actions
If you gain the same Action from multiple sources (such as Talents or Effects), you do not gain multiple copies of the Action. Instead, you gain access to a single instance of the Action, and all benefits or penalties from each source apply to that one instance.

##### Restrictions
If you gain multiple of the same Action and one of them has a Restriction but the other does not. The final combined Action is considered to have no restrictions.

<br>

*There is a difference between restrictions and triggers. Such as "whenever you use Bolster" is a trigger and "You can only use Antagonize to target yourself" is a restriction.*
