# Taking an Action
Actions is how you in Emulate interact with the world.

## 1. Choose the Action and the Targets
Select the Action you want to take and declare any necessary targets. *You do not need to meet the Requirements of an Action to select it, but if you do not meet the Requirements by Step 6, the Action is counteracted.*

## 2. Expend Resources
Expend resources needed to use the Action, such as Seconds or Spell Points. If you do not have the necessary resources for the chosen Action, counteract the Action instead. *No resources are expended.*

## 3. Roll for the Action
Roll Attack Rolls, Damage Rolls, Saving Throws and Skill Checks for the Action.

## 4 Determine Success
For each target of the Action, determine the Success of the Action against that target.

## 5. Determine 'When' Triggers
Any Creature that can [[Perception | perceive]] you take your Action, can use one Action as long as that Action's Triggers are met. 

### 5.1 Resolve Any Triggered Actions
Resolve any Triggered Actions before continuing with your declared Action. To resolve an Triggered Action simple follow the steps for Taking an Action. If multiple creatures use Triggered Actions resolve in order of Dexterity (Highest to Lowest).

### 5.2 Determine Success
For each target of the Action, determine the Success of the Action against that target.

## 6. Determine Action Requirements
Before the Action can resolve, all Requirements of the Action must be checked.

### 6.1 Determine Action Requirements
If for any reason the Action's Requirements are not met, such as needing a hand free, the Action is counteracted. *When the Action is counteracted, it does not resolve and there are no 'After' Triggers.*

### 6.2 Determine Requirements for Action's Targets
If the Action has a target listed in parentheses (*Antagonize (You)*), it must target a creature that fits the listed condition. 

If for any reason a Target no longer fits the requirement, the Action does not affect them. 

If there is no longer any viable targets or the Action does not target a required creature, the Action is counteracted. *When the Action is counteracted, it does not resolve and there are no 'After' Triggers.*

## 7. Resolve the action
Do as described in the Action, such as moving, applying Conditions or applying Damage.

## 8. Determine 'After' Triggers
Any Creature that can [[Perception | perceive]] you take your Action, can use one Action as long as that Action's Triggers are met. 

### 8.1 Resolve Any Triggered Actions
Resolve any Triggered Actions after your declared Action. To resolve an Triggered Action simple follow the steps for Taking an Action. If multiple creatures use Triggered Actions resolve in order of Dexterity (Highest to Lowest).
