# Perception (Wis)
Perception covers all five base senses: sight, hearing, taste, touch and smell. A perception check can be specified to use a specific sense, such as Perception (Sight).

### Perception Examples
| Detail                                       | Perception DC                  |
| -------------------------------------------- | ------------------------------ |
| Hear the sound of battle                     | -10                            |
| Notice the stench of rotting garbage         | -10                            |
| Notice the smell of smoke                    | 0                              |
| Hear the details of a conversation           | 0                              |
| Notice a visible creature                    | 0                              |
| Hear the sound of a creature walking         | 5                              |
| Hear the details of a whispered conversation | 15                             |
| Notice a pickpocket                          | Opposed by [[Sleight of Hand]] |
| Notice a creature using [[Hide]]          | Opposed by [[Hide]]         |
