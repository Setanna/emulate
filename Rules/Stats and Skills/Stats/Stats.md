# Stats
Creatures of Emulate are made up and primarily defined by 6 core attributes known as stats. The 6 stats are split evenly up to 3 Physical stats; Strength, Dexterity, constitution, and 3 Mental stats; Wisdom, Intelligence, Charisma

## Physical

### Strength
| Stat Score | Example        | Light Load | Medium Load | Heavy Load | Description                           |
| ---------- | -------------- | ---------- | ----------- | ---------- | ------------------------------------- |
| -5         |                | 2 kg       | 4 kg        | 12 kg      | Can barely lift own limbs             |
| -4         |                | 6 kg       | 12 kg       | 18 kg      | Can be knocked over by strong breezes |
| -3         | Elderly Human  | 10 kg      | 20 kg       | 30 kg      |                                       |
| -2         |                | 14 kg      | 28 kg       | 42 kg      |                                       |
| -1         |                | 18 kg      | 36 kg       | 54 kg      |                                       |
| 0          | Human          | 22 kg      | 44 kg       | 66 kg      |                                       |
| +1         |                | 27 kg      | 54 kg       | 81 kg      |                                       |
| +2         |                | 33 kg      | 66 kg       | 99 kg      |                                       |
| +3         | Orc            | 40 kg      | 80 kg       | 120 kg     |                                       |
| +4         |                | 48 kg      | 96 kg       | 144 kg     |                                       |
| +5         | Ogre or Dragon | 60 kg      | 120 kg      | 180 kg     |                                       | 

**Size** For each size above medium double the loads, and for each size below medium half the loads. For Example a Large Horse with a Strength of 4 would have a Light Load of 96 kg.

**Load Penalties:** Being lightly encumbered brings no penalties, while being of Medium Load carries with it a -1 Strength and Dexterity Penalty. Heavy Load carries with it a -2 Strength and Dexterity Penalty.
