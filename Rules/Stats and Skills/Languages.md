# Languages
Languages are build up of 3 proficiencies: Untrained, Basic and Fluent.

<br>

**Untrained:** Creatures untrained in a language can't understand, speak, write or read it.

<br>

**Basic:** Creatures with a basic understanding of a language, as such they can understand, speak, write or read most of it, some sayings, words and dialects might go over their head. Basic Speech tends to be a bit slower with several stops to think of the right words, as such Creatures using the language takes a -2 [[Circumstance]] Penalty to all Charisma Rolls and all Action Rolls with the [[Language]] Trait.

<br>

**Fluent:** Creatures fluent in a language, can speak it without thinking twice and can most common sayings and dialects. 

<br>

A creature starts Untrained in all languages except one of their choice, which they start with at a Fluent level. For each Intelligence above 0, the creature can learn a language at a Basic Level or increase a language at the Basic level to Fluent.

<br>

Additional language can be bought at Character Creation for 1 XP for a basic Understanding and 2 XP for a Fluent Understanding. After Character Creation a new language at Basic Understanding can be purchased for 1 XP, a Basic Understanding can be increased to Fluent for 1 additional XP.
