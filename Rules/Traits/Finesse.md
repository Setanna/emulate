# Finesse
Any Talent or Action with the Finesse Trait can replace all instances of Strength with Dexterity, including requirements. Whether the Talent or Action uses Strength or Dexterity can be changed whenever the Talent or Action is used.

<br>

Any Weapon with the Finesse Trait that is used to make a [[Precise]] or [[Reckless]] [[Making an Attack | Attack]], can replace all instances of Strength with Dexterity.

<br>

By default, any Action, Talent or Weapon with the Finesse Trait is automatically assumed to be using the highest stat.
