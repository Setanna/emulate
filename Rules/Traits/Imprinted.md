# Imprinted
A creature affected by an effect with the Imprinted Trait only resolves the initial Saving Throw once per [[Resting#Preparation | Preparation]]. The total number rolled *(Including penalites, bonuses and so on)* for that Saving Throw Roll is recorded for that creature and reused for all subsequent interactions with that effect during the same [[Resting#Preparation | Preparation]].

<br>

While the creature remains subject to the effect, it does not attempt additional Saving Throws against that same effect. If the creature leaves and later re-enters the area during the same Preparation, it does not roll a new Saving Throw; instead, it reuses its stored number for that roll.

<br>

This applies regardless of which source is producing the effect. If a creature has a stored number for a named effect, that number is reused for all sources of that same effect during the current Preparation.

<br>

The stored number is cleared at the start of a new [[Resting#Preparation | Preparation]].

<br>

Additionally, if a Creature's Saving Throw would be modified by a penalty or bonus, this is applied to the Imprinted number.
