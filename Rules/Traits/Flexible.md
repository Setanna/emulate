# Flexible
Any Talent or Action with the Flexible Trait can replace all instances of Strength with Dexterity, including requirements. Whether the Talent or Action uses Strength or Dexterity can be changed whenever the Talent or Action is used.

<br>

Any Weapon with the Flexible Trait can Roll an Attack Roll using the Dexterity Stat instead of the Strength Stat.

<br>

By default, any Action, Talent or Weapon with the Flexible Trait is automatically assumed to be using the highest stat.
