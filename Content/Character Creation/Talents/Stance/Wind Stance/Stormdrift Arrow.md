**System:**
When you take an [[Rules/Traits/Attack | Attack]] Action using a Ranged Weapon, you may trace any path the projectile travels through. The first creature or object the projectile intersects becomes the target of the [[Rules/Traits/Attack | Attack]] Action.

The length of the path travelled is considered the range of the attack. So if the path is 20 meters but the target is only 5 meters away it still gets penalties as if it was shot from 20 meters away.

The [[Rules/Traits/Attack | Attack]] Action ignores any form of [[Benefiting from Cover | Cover]].
